## ⚡ Overview

**NEXUS 2026** is a futuristic, immersive 3D WebGL web portal designed for an international cybernetic technology festival. Built with high-performance **Three.js (r128)**, **Tailwind CSS**, and a **procedural Web Audio API synthesizer**, this application offers an uninterrupted sci-fi experience from the moment it opens.

---

## 🔥 Key Features

### 1. ⚡ Automatic Cyber Entrance (Buttonless)
* **Zero-Click Gateway Boot**: Features a 2.4-second diagnostic loading sequence with real-time percentage counter and terminal HUD logs.
* **3D Hyperspace Warp Camera Zoom**: Once initialized, the camera smoothly warp-dives directly into the glowing 3D Quantum Core without requiring manual button clicks.

### 2. 🔊 High-Definition Web Audio Synthesizer Engine
* **Loud Sci-Fi Sound Effects**: High-gain audio synthesizers with dual-oscillator ambient drones (`A1 55Hz` + `E2 82.4Hz`).
* **Interactive Sound FX**:
  * **Hyperspace Laser Sweep (`sfxWarpIntro`)**: Dynamic pitch sweep from 140Hz up to 3400Hz.
  * **Sub-Bass Shockwave (`sfxShockwave`)**: 240Hz → 24Hz sub-bass impact thud for section transitions.
  * **Multi-Harmonic Chime (`sfxNavClick`)**: High-contrast click feedback on filters and links.
  * **Celebration Fanfare (`sfxCelebration`)**: Multi-note synth chord upon ticket minting and registration.

### 3. 🌌 Interactive 3D Three.js Quantum Core
* **Gyroscopic Torus Knot & Satellite Mesh**: Dynamic rotating quantum core with glowing wireframe rings.
* **Particle Cloud & Physics Tuner**: Live controls to tune core rotation speed, particle density (up to 5,000 nodes), entropy distortion, and color themes (Cyan, Emerald, Violet, Amber).

### 4. 🏆 Arena Competitions & Live Filter
* Live category filter (**AI & Robotics**, **CyberSecurity**, **Quantum Computing**, **Web3 & FinTech**) and instant search across hackathons ($150,000+ prize pool).

### 5. 📅 Interactive Event Schedule
* Day-by-day toggle (Day 1: Quantum Inception, Day 2: Cyber Synthesis, Day 3: Singularity Convergence) with search filtering and direct RSVP seat booking modal.

### 6. 🎟️ VIP HoloPass Generator & PNG Export
* Interactive 3D tilt credential badge with custom callsign/handle, avatar picker, celebratory confetti burst (`canvas-confetti`), and instant high-resolution PNG download (`html2canvas`).

### 7. 🤖 NEXUS-AI Assistant Chat HUD
* Sci-fi overlay assistant providing instant guidance on tracks, schedules, registration, and badge minting.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **3D Rendering**: Three.js (r128 WebGL)
* **Styling**: Tailwind CSS (Dark Void Theme, Glassmorphic HUDs, Neon Glows)
* **Audio Synthesis**: Web Audio API (Oscillators, Biquad Filters, Gain Nodes, LFOs)
* **Libraries**: `canvas-confetti`, `html2canvas`
* **Typography**: Orbitron, Rajdhani, JetBrains Mono

## 🚀 Quick Start

No package manager or build step is required! Simply clone the repository and open `index.html` in any browser:

```bash
# Clone the repository
git clone https://github.com/preksha-vijayvargiya/nexus-2026-techfest.git

# Navigate into the project folder
cd nexus-2026-techfest

# Open index.html in your default browser
```
